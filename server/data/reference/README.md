# 🛡️ سجلات المراجع الثابتة والمحمية (Reference Registries)

يحتوي هذا المجلد (`server/data/reference/`) على المراجع الثابتة والمحمية لنظام متابعة التعديات لشركة المياه الوطنية (NWC). 

> [!IMPORTANT]
> **قاعدة حماية قصوى:**
> الملفات الموجودة في هذا المجلد هي ملفات مرجعية دائمة (Static Reference Data). **ممنوع بتاتاً** مسحها، أو استبدالها تلقائياً، أو إعادة كتابتها عند رفع ملفات إكسل جديدة عبر واجهة النظام أو API (`/api/upload-reports`).

## ⚖️ القاعدة الذهبية لتصنيف المقاولين

1. **المقاول الرأسمالي (Capital Projects Contractor):**
   - هو مقاول مسجل رسمياً في وثائق مشاريع شركة المياه الوطنية (`NWC_Projects`) برقم مشروع واضح ومدير برنامج معتمد.
   - يتم ربط بلاغاته بمشروعه الرأسمالي الجاري أو عقده الشامل بشرط توافقه المكاني والتنظيمي.

2. **مقاول التشغيل والصيانة (Operation & Maintenance Contractor):**
   - يعمل على توصيلات منزلية، إصلاح انكسارات، طوارئ، أو عقود صيانة دورية بدون مشروع رأسمالي محدد.
   - **يُستبعد البلاغ مباشرة من المشاريع الرأسمالية** ويُصنف كـ `تشغيل وصيانة` مع ذكر السبب بدقة (`maintenance_contractor`).

3. **الاستثناءات المعتمدة بشروط مكانية:**
   - **شركة الأعمال المدنية المحدودة:** تُصنف صيانة عامة في كافة البلاغات، **باستثناء** مشروع شبكات صرف صحي بحي العوالي المرحلة الأولى (`#57`) تحت إشراف م. أمجد الفالح، إذا كان البلاغ يقع جغرافياً داخل حي العوالي.
   - **مؤسسة العرين للمقاولات:** تُصنف صيانة عامة، **باستثناء** مشروع شبكات مياه النرجس (`#59`) تحت إشراف م. عبدالله الأسود العنزي إذا طابق نطاق النرجس.
   - **شركة النمال للمقاولات مساهمة مقفلة:** لها عقد متفرقات صرف صحي `#61` وتخضع لشرط مكاني صارم (الوقوع الفعلي على خطوط الطبقة المعتمدة)؛ ما عدا ذلك يُستبعد للصيانة.

## 🔄 منطق الدمج الأسبوعي الآمن (Safe Weekly Merge Logic)

عند رفع تقرير أسبوعي جديد:
1. **عدم مسح التعديلات اليدوية:** ملف `overrides.json` ونسخته الاحتياطية لا يتم تصفيرهما بتاتاً. التعديلات اليدوية المعتمدة تُطابق وتُطبق بواسطة `reportId`.
2. **الحفاظ على الأرشيف التاريخي:** البلاغات التي كانت موجودة سابقاً واختفت من الملف الأسبوعي الجديد لا تُحذف؛ بل يتم وسمها كبلاغات تاريخية مؤرشفة (`isHistorical: true` أو `disappearedFromWeekly: true`) مع الاحتفاظ بكافة بياناتها السابقة.
3. **تطبيق التصنيف الصارم للمقاولين:** البلاغات المنسوبة لمقاولي الصيانة تُستبعد تلقائياً دون إسنادها لمشاريع رأسمالية، لحماية مؤشرات مدراء المشاريع والبرامج.
