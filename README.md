# 📊 نظام التعديات - إدارة وتدقيق البلاغات

نظام ويب تفاعلي لإدارة ومتابعة بلاغات التعديات على مشاريع المياه والصرف الصحي بمدينة الرياض والمحافظات.

## 🚀 البدء السريع

### المتطلبات
- Node.js v20+ (مثبت بالفعل: v24.21.0)
- npm (مثبت بالفعل: v11.19.0)

### خطوات التثبيت والتشغيل

```bash
# 1. ثبّت الـ dependencies
npm install

# 2. بناء قاعدة البيانات من الملفات الخام
npm run build-data

# 3. تشغيل الخادم والتطبيق معاً
npm run dev
```

سيفتح التطبيق تلقائياً على:
- **الواجهة الأمامية**: http://localhost:5173
- **API**: http://localhost:3000/api

## 📖 كيفية الاستخدام

### تحديث البيانات أسبوعياً

1. استبدل ملف الإكسل الأسبوعي:
   - ضع الملف الجديد في مجلد `XLSX/`
   - احفظه بنفس اسم الملف السابق: `بلاغات تعدي مقاولي شركة المياه الوطنية 12 سبتمبر.xlsx`

2. أضغط زر "تحديث البيانات" من لوحة التحكم، أو شغّل:
   ```bash
   npm run build-data
   ```

### الصفحات الرئيسية

- **📊 لوحة رئيسية**: ملخص الإحصائيات والمؤشرات الرئيسية
- **📋 جدول البلاغات**: عرض مفصل لكل البلاغات مع إمكانية الفرز والفلترة والتعديل
- **🗺️ الخريطة**: عرض تفاعلي لمواقع البلاغات والمشاريع
- **👥 بطاقات المدراء**: ملخص لكل مدير برنامج وبلاغاته
- **📄 التقرير الأسبوعي**: تصدير إنفوجرافيك وPDF

## 🔧 محرك المعالجة

المحرك الذكي يقوم بـ:

1. **قراءة البيانات**: استخراج البلاغات والمشاريع والخرائط من الملفات
2. **المطابقة الآلية**: ربط كل بلاغ بالمشروع الصحيح باستخدام:
   - التحقق الجغرافي (GIS): هل النقطة قريبة من حدود المشروع؟
   - مطابقة المقاول: هل اسم المقاول يطابق؟
   - مطابقة الحي: هل الحي يقع ضمن نطاق المشروع؟
3. **الاستبعاد الذكي**: تمييز بلاغات التشغيل والصيانة والطوارئ
4. **حساب مؤشرات**: أيام التأخير، مستوى الثقة، التوجيه الميداني المطلوب
