# 📤 ميزة رفع ملفات Excel الجديدة

## 🎯 الغرض

بدلاً من استبدال الملف يدوياً وتشغيل أوامر من Terminal، يمكنك الآن:
1. **رفع ملف Excel مباشرة من الواجهة**
2. **معالجة البيانات تلقائياً**
3. **تحديث الخريطة والجداول والإحصائيات فوراً**

---

## ✨ الميزات

### 1. **واجهة رفع ذكية**
- ✅ رفع بـ Drag & Drop (سحب وإفلات)
- ✅ واجهة رفع تقليدية (اضغط لاختيار)
- ✅ التحقق من نوع الملف (Excel فقط)
- ✅ التحقق من حجم الملف (الحد الأقصى 50 MB)

### 2. **معالجة تلقائية**
```
رفع الملف
  ↓
التحقق من الصيغة والحجم
  ↓
استبدال الملف القديم
  ↓
تشغيل معالج البيانات تلقائياً
  ↓
تحديث جميع البيانات والخرائط
```

### 3. **تحديث فوري**
- لا حاجة لإعادة تشغيل الخادم
- البيانات تُحدّث في الوقت الفعلي
- الواجهة تُعيد تحميل الإحصائيات تلقائياً

---

## 🚀 كيفية الاستخدام

### الخطوة 1: فتح لوحة المراقبة
```
الرابط: http://localhost:5173 (أو Railway URL)
الصفحة: لوحة المراقبة (Dashboard)
```

### الخطوة 2: البحث عن قسم "رفع البلاغات"
ستجد في أعلى الصفحة بطاقة بعنوان:
```
📤 رفع ملف البلاغات الجديد
```

### الخطوة 3: رفع الملف

**طريقة 1: Drag & Drop (الأسهل)**
```
1. افتح explorer وابحث عن ملف البلاغات الجديد
2. اسحب الملف إلى منطقة الرفع الزرقاء
3. أفلته فيها
```

**طريقة 2: الضغط**
```
1. اضغط على منطقة الرفع
2. اختر الملف من المتصفح
3. اضغط "فتح"
```

### الخطوة 4: انتظر المعالجة
```
⏳ جاري المعالجة... [████████████] 85%
```

- شريط تقدم يظهر أثناء المعالجة
- لا تغلق الصفحة حتى اكتمال المعالجة
- الوقت المتوقع: **2-5 دقائق** حسب حجم الملف

### الخطوة 5: تأكيد النجاح
```
✅ تم رفع الملف بنجاح! تم معالجة البيانات تلقائياً.
```

---

## 📊 ما يحدث تلقائياً

عند رفع ملف جديد، النظام يقوم بـ:

| الخطوة | الوصف |
|-------|------|
| 1️⃣ | ✅ التحقق من أن الملف Excel صحيح |
| 2️⃣ | ✅ استبدال `XLSX/بلاغات تعدي...xlsx` الملف القديم |
| 3️⃣ | ✅ تشغيل `npm run build-data` تلقائياً |
| 4️⃣ | ✅ قراءة 4000+ بلاغ من الملف الجديد |
| 5️⃣ | ✅ مطابقة الذكية مع المشاريع (Spatial + Fuzzy) |
| 6️⃣ | ✅ توليد البيانات الجديدة في `server/data/generated/` |
| 7️⃣ | ✅ تحديث الخريطة والجداول والإحصائيات |

## 🎨 حالات الرفع

### ✅ نجح
```
✅ تم رفع الملف بنجاح! تم معالجة البيانات تلقائياً.
```
- الملف تم معالجته بنجاح
- جميع البيانات محدّثة
- تحديث الصفحة تلقائي

### ❌ خطأ في النوع
```
❌ يجب أن يكون الملف بصيغة Excel (.xlsx أو .xls)
```
- الملف ليس Excel
- حاول بملف `.xlsx` أو `.xls`

### ❌ خطأ في الحجم
```
❌ حجم الملف كبير جداً (الحد الأقصى 50 MB)
```
- ملف كبير جداً
- حاول بملف أصغر من 50 MB

### ❌ خطأ في المعالجة
```
❌ خطأ: [تفاصيل الخطأ]
```
- خطأ في معالجة البيانات
- تحقق من صيغة الملف
- جرّب مع ملف سابق يُعرف أنه يعمل

## 📞 استكشاف الأخطاء

### المشكلة: الملف لا يرتفع
**الحل:**
- تحقق من اتصال الإنترنت
- تأكد أن الخادم يعمل
- جرّب ملف أصغر

### المشكلة: المعالجة بطيئة جداً
**الحل:**
- قد تكون البيانات كبيرة جداً
- الخادم قد يكون مشغول
- جرّب لاحقاً

### المشكلة: البيانات لم تُحدّث
**الحل:**
- أعد تحميل الصفحة (F5)
- امسح cache المتصفح (Ctrl+Shift+Delete)
- تحقق من حالة الملف المرفوع
